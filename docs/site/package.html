mcsimr

A local-first R package and Shiny workbench for reproducible Monte Carlo simulation studies, built first for lavaan and structural equation modeling.

Open the app View on GitHub

What It Does

Design Conditions

Vary sample sizes, estimators, and lavaan population parameters such as loadings, variances, covariances, regressions, and intercepts.

Run Locally

Run simulations on your own computer with multiple workers, checkpoint each condition, and resume long jobs without starting over.

Export Research Artifacts

Generate APA-style tables, visualizations, raw LaTeX model equations, reproducible R code, and a Quarto project.

Install

install.packages("remotes")

Example

library(mcsimr)

pc <- sem_parameter_conditions(
  lhs = c("f", "f"),
  op = c("=~", "~~"),
  rhs = c("y2", "f"),
  values = list(c(0.60, 0.80), c(0.80, 1.00))
)

spec <- sem_sim_spec(
  population_model = "f =~ 0.70*y1 + 0.80*y2 + 0.90*y3
f ~~ 1*f
y1 ~~ 0.51*y1
y2 ~~ 0.36*y2
y3 ~~ 0.19*y3",
  fitted_model = "f =~ y1 + y2 + y3",
  n = c(100, 250, 500),
  reps = 1000,
  parameter_conditions = pc
)

study <- run_simulation_study(spec, workers = 4, resume = TRUE)
