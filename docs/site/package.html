mcsimr

mcsimr is an open-source R package and local Shiny workbench for designing, running, checkpointing, and reporting Monte Carlo simulation studies. The primary target is lavaan SEM, with OLS regression included as a simpler first engine.

lavaan SEM Parallel workers Checkpoints APA tables Quarto export

Why Use mcsimr?

Monte Carlo studies are most useful when the design is explicit: the data-generating model, fitted model, manipulated conditions, random seed, performance metrics, and reporting workflow should all be inspectable and reproducible.

  • simulation setup is stored as an R specification object;
  • long-running jobs can checkpoint each condition and resume later;
  • local runs can use multiple CPU workers;
  • SEM users can vary sample size, estimator, and specific lavaan population parameters;
  • results export to APA-style tables, figures, raw LaTeX equations, and runnable Quarto projects.

What the App Looks Like

The app is organized as a research workflow rather than a single formula box:

Model Builder

Build or paste lavaan syntax, preview equations, and load the Political Democracy SEM example.

Conditions

Vary parameters using rows such as f =~ y2: 0.60, 0.80 or dem65 ~ dem60: 0.65, 0.85.

Results

Inspect bias, MSE, RMSE, coverage, power, Type I error, convergence, improper solutions, and fit indices.

Getting Started

Launch the local desktop app from R:

library(mcsimr)
use_mcsimr_app()

Or define a SEM simulation directly in code:

pc <- sem_parameter_conditions(
  lhs = c("f", "f"),
  op = c("=~", "~~"),
  rhs = c("y2", "f"),
  values = list(c(0.60, 0.80), c(0.80, 1.00))
)

spec <- sem_sim_spec(
  population_model = "f =~ 0.70*y1 + 0.80*y2 + 0.90*y3
f ~~ 1*f
y1 ~~ 0.51*y1
y2 ~~ 0.36*y2
y3 ~~ 0.19*y3",
  fitted_model = "f =~ y1 + y2 + y3",
  n = c(100, 250, 500),
  reps = 1000,
  parameter_conditions = pc
)

study <- run_simulation_study(
  spec,
  workers = 4,
  checkpoint_dir = "results/checkpoints",
  resume = TRUE
)
